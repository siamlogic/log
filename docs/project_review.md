## 3. 臨床・原本適合性およびUI/UX評価 (非セキュリティ重点検証)

### 3.1 原本Excel（厚労省SCBTシート）との整合性
- **時間軸と曜日配列**: 原本（`reference/SCBT_2_katsudokiroku.xls`）の「月曜日始まり」「午前0～1時」から「午後11～0時」までの全24区分を完全踏襲しており、臨床現場で使われている紙・Excelシートから違和感なく移行可能です。
- **睡眠・休息枠の自然な表現**: 原本記入例（`reference/EX_SCBT_shukankatsudou.xls`）と同様に、睡眠時間帯は活動名に「就寝」「睡眠」と記載し、気分スコアを空欄（`null`）とすることで、日中の活動に伴う気分の波を正確に客観視できます。
- **感情カスタマイズと極性統一**: `emotion_label`（「気分の良さ」「楽しみ度」「達成感」「充実度」等）により、当事者の臨床的課題に応じた柔軟な記録対象を設定可能。内部スコアは `1.00 = 最良, 0.00 = 最悪` の単一極性に統一され、臨床グラフの歪みを防止。

### 3.2 UI/UX・マルチデバイス・アクセシビリティ
- **デバイス別の最適化**:
  - **PC / 横向きタブレット**: 24時間×7日間の全体像を一望できる週間マトリクス（`SCR-101`）。1024px未満でもレイアウトが破綻しない横スクロール対応（`min-w-[1020px]`）。
  - **スマートフォン縦画面**: 1日24時間の縦スクロールタイムライン（`SCR-102`）。左右のスワイプ・日送りボタン（◀/▶）や各種アクションボタンは、片手操作に適した大型タップターゲット（`min-h-[44px]`）を維持。
- **入力フリクションの低減**:
  - クイック活動タグ（「起床」「朝食」「就寝」等）による1タップ入力。
  - 「就寝」タグ選択時の8時間範囲一括設定 & 気分自動クリア（`null`）。
  - 後続スロットの同一活動連続時間自動カウント（`detectedDuration`）。
- **色覚多様性（WCAG 2.1 AA準拠）**:
  - 気分状態の伝達において、色だけでなく「記号」と「数値パーセント」を必ず同時に表示。色覚特性（P型・D型色覚など）に関わらず、直感的な自己モニタリングが可能。
