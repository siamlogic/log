# メンバー（利用者）向け利用ガイド (User Guide)

- **文書ID**: D-13
- **バージョン**: 1.0.0
- **改定日**: 2026-10-16
- **対象読者**: CBT週間活動記録システムをご利用のメンバーの皆様

---

## 1. はじめに

このシステムは、日々の活動や気分の推移をスマートフォンやパソコンから手軽に記録し、生活リズムや気分の波を客観的に見つめ直すためのセルフモニタリング支援ツールです。

---

## 2. 画面の見方と基本入力

### 2.1 3つの表示モード
画面上部のタブから、状況に合わせて表示を切り替えられます。
- **週表示（週間マトリクス）**: PCやタブレットに最適。1週間（月曜日〜日曜日）の24時間の流れを一覧で見渡せます。
- **日表示（タイムライン）**: スマートフォンでの片手入力に最適。1日の活動を時系列でスムーズに記録できます。
- **月表示（ヒートマップ）**: 月間カレンダー形式で、記録のついている日や日ごとの気分の波を色で確認できます。

### 2.2 1時間枠の記録手順
1. 記録したい時間枠（例: 午前10〜11時）をクリックまたはタップします。
2. 入力画面（モーダル）が開きます。
   - **活動内容**: 何をしていたかを入力します（例: 「散歩」「朝食」「デスクワーク」「読書」）。
   - **気分の記録**: そのときの気分マーク（天気・表情・矢印など）を選びます。
   - **睡眠や就寝中**: 就寝していた時間枠は、活動内容に「睡眠」や「就寝」と入力し、気分は未選択（または「気分を記録しない」）のまま保存できます。
   - **メモ**: 気づいたことや状況を自由に入力できます。
3. 「保存する」を押して完了です。

---

## 3. 入力をもっと楽にする便利機能

### 3.1 過去日のコピー (`SCR-105`)
「昨日と同じような生活リズムだった」というときは、過去日のコピーが便利です。
- 画面上部の「過去日からコピー」を選択します。
- コピー元の「日付」を選びます。
- **安心設計**: 初期状態では「空いている枠のみ反映」されるため、すでに入力した枠が消えてしまう心配はありません。また、気分のコピーを含めるかも選択できます。

### 3.2 定型ルーティン（テンプレート）の活用 (`SCR-106`)
平日出勤、在宅勤務、休日、療養日などの決まった予定をワンタップで反映できます。
- 画面上部の「定型パターン」をクリック。
- 「平日出勤」「在宅勤務」「休日リフレッシュ」「自宅療養」などから選び、「反映する」を押すだけで、該当日のタイムラインに予定が展開されます。

### 3.3 気分マークのカスタマイズ (`SCR-107`)
画面右上の「気分設定」から、自分に合った記録スタイルへ変更できます。
- **感情の名前**: 「気分の良さ」のほか、「楽しみ度」「達成感」「充実度」など、自分が注目したい感情名に変更できます。
- **アイコンスタイル**: 5つのスタイルから選べます。
  - 🌤️ **お天気**（快晴 〜 雨・雷）
  - 😊 **表情・フェイス**（笑顔 〜 困り顔）
  - ⚾ **パワプロ調子**（絶好調 〜 絶不調）
  - ⬆️ **調子矢印**（大幅良 〜 大幅悪 ※その時点の調子の向き）
  - 🔢 **数値パーセント**（100% 〜 0%）
- **段階数**: 3段階から最大11段階まで、記録しやすい細かさに調整できます。

## 4. 安全にご利用いただくために

- **共用パソコンでのご利用**: 図書館や職場等の共用端末をご利用の場合、作業完了後は必ず右上の「ログアウト」を押してください。また、万が一離席した場合でも、30分間無操作が続くと安全のため自動的にログアウトされます。
