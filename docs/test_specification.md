## 1. テスト計画概要

本テスト仕様書は、CBT週間活動記録システムにおける品質担保、臨床データ整合性、および最高水準のセキュリティ要件（Zero Trustアクセス分離、IDOR遮断、機微カルテ保護、2FA TOTPリプレイ耐性、仮登録〜本登録フロー）の検証計画を定義します。

---

## 3. テスト実行環境 & 手順

本システムは **Dockerを一切使用せず**、Node.js ネイティブ環境でテストを実行します。

```bash
# データベースの初期化 & シード投入
npx prisma db push
node prisma/seed.js

# 本番ビルド & サーバー起動 (ポート 3001)
npm run build
$env:PORT=3001; npm run start

# 自動テストの実行 (全36項目一括検証)
npm test
```
