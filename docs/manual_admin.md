# 管理者（カウンセラー・医師・サポーター）操作マニュアル

- **文書ID**: D-12
- **バージョン**: 1.1.0
- **改定日**: 2026-10-21
- **対象読者**: カウンセラー、臨床心理士、医師、支援スタッフ

---

## 1. はじめに

本システムは、認知行動療法（CBT）の「行動活性化法」において、担当メンバーの日々の活動記録や気分の推移をオンライン上で伴走支援するためのWebシステムです。

> **重要なお知らせ**:
> - 個人情報保護および医療情報セキュリティの観点から、**本システムにはExcel/CSV等のファイルダウンロード・エクスポート機能は一切設けておりません**。記録の確認・振り返りは、すべて認証下のセキュアな画面上で行ってください。

---

## 2. 画面構成と基本操作

### 2.1 担当メンバー一覧 (`SCR-201`)
ログイン後、上部ナビゲーションの「担当メンバー一覧」をクリックします。
- **メンバーカード表示**: 担当しているメンバーの氏名、メールアドレス、支援ステータス（進行中 `active` / 休止 `paused` / 完了 `completed`）が表示されます。
- **表示 / 非表示（アーカイブ切替）**:
  - 各カードの目玉アイコン（👁️「非表示にする」）をクリックすると、そのメンバーが一覧から隠され、アクティブな支援対象のみに整理できます。
  - 画面上部の「非表示メンバーを表示する」チェックボックスをONにすると、非表示中のメンバーが薄いグレー表示で一覧に現れ、目玉スラッシュアイコン（👁️‍🗨️「再表示する」）を押すことでいつでも通常表示に戻せます。

### 2.2 週間活動記録の閲覧 (`SCR-202`)
メンバーカードの「シート閲覧・支援カルテ」をクリックすると、そのメンバーの記録画面が開きます。
- **週送りナビゲーション**: 画面上部の「◀ 前週」「翌週 ▶」ボタンで、過去週の記録へ素早く切り替えられます。
- **気分推移グラフ**: シート上部に、月曜日から日曜日までの日別平均気分の折れ線グラフが表示され、1週間のコンディションの波をひと目で把握できます。
- **スロット詳細**: 各時間枠にカーソルを合わせると、活動内容や補足メモを確認できます。

### 2.3 支援者専用カルテ・非公開メモ (`SCR-203`)
画面上部の「支援メモ（本人非公開カルテ）」パネルにて、面談での気づきや今後の支援方針を記録できます。

- **絶対秘匿の保証**:
  本メモは、**メンバー本人の画面・通信データ（APIレスポンス）から完全に遮断（完全除外）**されています。メンバー本人がブラウザの開発者ツール等を用いても閲覧することは絶対にできません。安心して率直な臨床見解や支援方針を記録してください。
- **自動保存・更新証跡**: メモを入力して「支援メモを保存」をクリックすると、更新日時と更新者名が記録されます。

### 2.4 メンバー新規仮登録・招待発行 (`SCR-204`)
新しいクライアント（メンバー）の支援を開始する際、管理者が仮登録を行います。

1. メンバー一覧画面右上の「+ メンバー招待」ボタンをクリックします。
2. モーダルで以下を入力します：
   - **メールアドレス**: メンバーの連絡先メールアドレス（必須）
   - **氏名・表示名**: システム内での呼称（必須）
   - **初期支援ステータス**: 「進行中（active）」を選択
3. 「招待を発行する」をクリックすると、システム上でアカウントが仮登録（`status: invited`）され、**48時間有効な初回登録用ワンタイムトークン**が発行されます。
4. 画面上に表示された「初回パスワード設定URL」をコピーし、メンバーへ安全に案内します（メール送信機能連携時は自動送信）。

### 2.5 メンバー側の初回パスワード設定と運用開始の流れ
1. メンバーが案内されたURL（例: `https://<domain>/?mode=setup&token=...&email=...`）にアクセスします。
2. ログイン画面の「初回パスワード設定」モードが自動で開き、メンバー自身が任意のパスワード（8文字以上）を設定します。
3. パスワード設定が成功すると、アカウントが正式に有効化（`status: active`）され、自動的にログインしてその日からCBT記録の運用が開始されます。
